# 🏦 Loan Default Risk Analysis Dashboard

An interactive **Loan Default Risk Analysis Dashboard** built using **Power BI, DAX, Power Query, Python, and SQL** to analyze loan applications, customer profiles, loan risk, default behavior, and financial patterns.

The project transforms raw loan data into an interactive business intelligence solution that helps identify **default risk, customer patterns, loan performance, and key financial insights**.

---

# 📊 Project Overview

This project focuses on analyzing loan application and customer data to understand the factors associated with **loan default risk**.

The analysis combines:

* Customer analysis
* Loan analysis
* Default risk analysis
* Financial analysis
* Customer segmentation
* Interactive Power BI reporting
* Python-based data analysis

The goal is to convert raw loan data into meaningful insights that can support **data-driven lending and risk-management decisions**.

---

# 🎯 Project Objectives

The main objectives of this project are:

* Analyze loan applications
* Understand customer characteristics
* Identify default-risk patterns
* Analyze loan performance
* Compare customer segments
* Identify high-risk groups
* Explore relationships between customer and loan attributes
* Build interactive Power BI dashboards
